ICU Mortality Modeling | ML/Data Science Engineer

Applied machine learning to the MIMIC-III dataset to predict ICU patient mortality using vitals, comorbidities, and diagnostic codes. Built interpretable and deep learning models with ROC-based evaluation and rigorous preprocessing.

Finance vs Birdsong - Time Series Classification | ML/Data Science Engineer

Compared linear and tree-based classifiers to distinguish financial vs birdsong time series based on extracted statistical features, using R's tidymodels. Included ROC-based evaluation and visual interpretations.

Forecasted monthly turnover in NT's electronics retail sector using ETS and ARIMA. Included STL decomposition, Box-Cox transforms, unit root tests, and 2-year validation with updated ABS data.
